# Historical telematics documentation archive

Archived on 2026-10-24 after the user approved telematics/RC-only consolidation
and archiving rather than permanent deletion.

**Current guidance:** [Telematics and RC Research](../../telematics-master-plan.md).
These fourteen guides are historical references only. They may contain superseded
requirements, contradictions, retired iOS/mobile-browser instructions, unimplemented
proposals, and dated verification. Do not treat them as instructions to restore
old behavior or as evidence that a planned feature is implemented.

The working copies, including pre-existing uncommitted edits, were preserved with
an archive banner and rebased relative Markdown links. No substantive historical
body text was intentionally removed. Hashes below identify the original working
copies before those presentation/link changes; they are not hashes of the archived
files. Archive retrieval is optional historical research, not mandatory coding input.
The retained Android-only scope and unrelated domain guides remain outside this archive.
